Uploading writes to the website’s GitHub repository, so this device needs a token once. It is stored in this browser only — not on the website, and never shared with visitors. Use a private device, and remove it below if the device is lost.

  1. Sign in to GitHub and open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate a token with access to WALTERNTECH/Willy-Auto-Garage only.
  3. Under Repository permissions, set Contents to Read and write.
  4. Copy the token and paste it here.

No token? You can still use every slot below — the photo is resized and downloaded with the correct filename, ready to hand to whoever manages the site.
